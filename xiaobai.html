Claude Code 下载 & 安装教程

跟着本页一步步操作，15 分钟即可完成

1

安装 Node.js（必须的第一步）

Claude Code 需要一个叫 Node.js 的运行环境。你只需要安装它，不需要学它。

👉 点击下面按钮，下载 Node.js 安装包：

🔗 打开 Node.js 官网下载

打开网页后，你会看到两个绿色大按钮：

  • 点左边的 LTS 按钮（长期支持版，最稳定）
  • 下载完成后，双击 下载的文件
  • 一路点 「Next >」（下一步），不用改任何选项
  • 最后点 「Install」（安装），等进度条跑完
  • 安装完点 「Finish」
💡 就像安装普通软件一样，一直点"下一步"就行。不需要改任何设置。

验证安装成功：

在电脑搜索框输入 PowerShell，打开后输入：

node --version

如果看到一行数字（如 v22.12.0），说明安装成功 ✅

⚠️ 如果显示"不是内部命令"或报错，重启电脑再试。
2

安装 Claude Code

确保第一步的 Node.js 装好了，然后开始装 Claude Code。

1. 打开 PowerShell

点电脑左下角「开始」→ 输入 PowerShell → 点击打开（蓝色图标那个）

2. 复制下面这行命令

npm install -g @anthropic-ai/claude-code

3. 粘贴到 PowerShell 里，按回车

在 PowerShell 窗口里右键一下，命令就粘贴进去了（或者按 Ctrl + V），然后按 Enter。

📺 粘贴命令 → 按回车 → 等待 1-2 分钟 → 看到安装完成提示
✅ 看到 added xxx packages 或者没有任何红色报错，就是安装成功了。

4. 验证安装：

claude --version

显示版本号（如 1.0.37）就是装好了 🎉

3

第一次启动 Claude Code

在 PowerShell 里输入这个命令，然后按回车：

claude

第一次启动会有几个步骤：

  1. 自动下载：第一次会下载一个核心程序，大约 50MB，等 1-2 分钟
  2. 登录验证：浏览器会弹出一个网页，让你登录 Anthropic 账号。你也可以点"使用 API Key"跳过
  3. 进入对话：验证完后回到终端，看到聊天界面就是成功了！
🔑 第一次使用需要什么？
· 方式一：用 Google/GitHub 账号登录（最简单）
· 方式二：用 API Key（需要去 Anthropic 官网注册充值，或者用 DeepSeek 的 Key）
⚠️ 如果卡在"正在下载"很久不动，说明网络不好。按 Ctrl + C 关掉重试，或者换个网络环境。
4

开始使用 —— 跟 Claude Code 对话

启动成功后，你会看到一个对话界面。直接用中文打字就能跟它交流。

试试这几个指令：

帮我看看我电脑上装了什么软件
分析一下C盘空间占用情况
帮我写一个简单的计算器程序

想退出时，输入 /exit 或按 Ctrl + C。

🎉 恭喜！你已经成功安装并可以使用 Claude Code 了！

常见问题

Q: 安装时一直转圈/下载慢怎么办？

A: 可能是网络问题。试试关闭防火墙/杀毒软件，或者连手机热点重试。

Q: PowerShell 显示红字报错？

A: 截图保存报错内容，然后去 Claude Code GitHub 搜一下有没有同样的问题。

Q: 我想用 DeepSeek 的 API Key 怎么办？

A: 参考 进阶安装教程，里面有 DeepSeek 和 CC-Switch 的详细配置方法。

Q: Claude Code 收费吗？

A: 工具本身免费。但使用需要 API Key（按用量收费）或 Anthropic 订阅。DeepSeek API 是目前最便宜的选择，充值 10 块钱能用很久。
