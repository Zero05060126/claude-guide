Claude Code 下载 & 安装教程

跟着本页一步步操作，15 分钟即可完成

1

安装 Node.js（必须的第一步）

Claude Code 需要一个叫 Node.js 的运行环境。你只需要安装它，不需要学它。

👉 点击下面按钮，下载 Node.js 安装包：

🔗 打开 Node.js 官网下载

打开网页后，你会看到两个绿色大按钮：

  • 点左边的 LTS 按钮（长期支持版，最稳定）
  • 下载完成后，双击 下载的文件
  • 一路点 「Next >」（下一步），不用改任何选项
  • 最后点 「Install」（安装），等进度条跑完
  • 安装完点 「Finish」
💡 就像安装普通软件一样，一直点"下一步"就行。不需要改任何设置。

验证安装成功：

在电脑搜索框输入 PowerShell，打开后输入：

node --version

如果看到一行数字（如 v22.12.0），说明安装成功 ✅

⚠️ 如果显示"不是内部命令"或报错，重启电脑再试。
2

安装 Claude Code

确保第一步的 Node.js 装好了，然后开始装 Claude Code。

1. 打开 PowerShell

点电脑左下角「开始」→ 输入 PowerShell → 点击打开（蓝色图标那个）

2. 复制下面这行命令：

npm install -g @anthropic-ai/claude-code

3. 粘贴到 PowerShell 里，按回车

在 PowerShell 窗口里右键一下，命令就粘贴进去了，然后按 Enter。

等待 1-2 分钟，看到安装完成提示即可。

✅ 看到 added xxx packages 或者没有任何红色报错，就是安装成功了。

4. 验证安装：

claude --version

显示版本号就是装好了 🎉

3

第一次启动 Claude Code

在 PowerShell 里输入：

claude

第一次启动：

  1. 自动下载核心程序（约 50MB，1-2 分钟）
  2. 浏览器弹出登录页，用 Google/GitHub 账号登录（或用 API Key）
  3. 验证完后进入对话界面，成功！
⚠️ 如果卡在下载很久不动，按 Ctrl + C 关掉重试。
