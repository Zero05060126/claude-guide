1 用 QClaw 安装 Claude Code

QClaw 是第三方桌面管理工具，图形化一键安装，无需敲命令。

1.1 打开 QClaw 官网下载

https://qclaw.app

用浏览器打开 → 点击「下载」→ 双击安装包 → 按提示完成安装 → 启动 QClaw。

1.2 在 QClaw 中安装 Claude Code

  1. 启动 QClaw，进入主界面
  2. 点击左侧菜单 「安装 Claude Code」
  3. 点击 「一键安装」
  4. 等待自动完成 Node.js 检测 + Claude Code 安装（约 2 分钟）
  5. 看到 "已安装" 即完成

1.3 验证安装

在 QClaw 的命令输入框输入：

claude --version

返回版本号（如 v1.0.x）说明安装成功。

QClaw 自动处理 Node.js 依赖，你不需要手动安装任何其他东西。

2 注册 DeepSeek 获取 API Key

Claude Code 默认走 Anthropic 官方 API（贵且需海外卡）。接 DeepSeek V4 Pro 只要很低成本，够日常用很久。

2.1 注册账号

https://platform.deepseek.com
  1. 打开网址 → 点 「注册」（手机号或邮箱）
  2. 注册完登录，进入控制台

2.2 创建 API Key

  1. 左侧菜单点 「API Keys」
  2. 点 「创建 API Key」
  3. 名称填 "Claude Code"，点确认
  4. 页面弹出以 sk- 开头的密钥
  5. 立刻复制粘贴到记事本保存！ 关闭后再也看不到

2.3 充值（最低 10 元）

  1. 左侧点 「充值」
  2. 最低充 10 元，每天用够撑几个月
API Key 只显示一次！请务必复制保存到安全的地方。

2.4 在 Claude Code 中配置 DeepSeek

方式一：QClaw 图形化配置（推荐）

  1. QClaw → 「设置」 → 「模型配置」
  2. API 地址填：https://api.deepseek.com/v1
  3. API Key 填：刚才保存的 sk-xxxx
  4. 模型名选：deepseek-chat
  5. 点「保存」→「测试连接」→ 绿色 即成功

方式二：手动设环境变量

打开 PowerShell，逐条执行（替换 你的key）：

[Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "你的key", "User")
[Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.deepseek.com/v1", "User")
[Environment]::SetEnvironmentVariable("ANTHROPIC_DEFAULT_HAIKU_MODEL", "deepseek-chat", "User")
[Environment]::SetEnvironmentVariable("ANTHROPIC_DEFAULT_SONNET_MODEL", "deepseek-chat", "User")
[Environment]::SetEnvironmentVariable("ANTHROPIC_DEFAULT_OPUS_MODEL", "deepseek-chat", "User")

执行完重启 QClaw，配置生效。

2.5 验证

claude -p "你是什么模型"

回复含 "DeepSeek" 即配置正确

3 用 CC-Switch 管理模型切换

CC-Switch 让你在 Claude 官方和 DeepSeek 之间一键切换，不同任务选不同模型。

3.1 下载 CC-Switch

https://cc-switch.app

浏览器打开 → 点「下载」→ 双击安装 → 启动（系统托盘出现图标）。

3.2 添加 DeepSeek 模型

  1. 打开 CC-Switch → 「模型管理」
  2. 点 「添加模型」
  3. 选择 DeepSeek V4 Pro
  4. 填入你的 API Key（第 2 步获取的那个）
  5. API 地址设为：https://api.deepseek.com/v1
  6. 保存

3.3 一键切换模型

  1. CC-Switch 主界面选择当前想用的模型
  2. 选 DeepSeek：便宜日常用
  3. 选 Claude：复杂任务用
  4. 切换即生效，无需重启
状态栏显示 "DeepSeek V4 Pro 已连接" 即一切就绪。

附赠：让 Claude Code 帮你清理 C 盘

安装完成后，在终端（或 QClaw 指令框）输入：

claude -p "分析C盘空间占用，找出可清理的临时文件、缓存、旧驱动安装包、浏览器缓存，列出清单让我确认后清理。危险操作必须先征得我同意。"

Claude Code 会自动扫描 C 盘，给你一份清理清单，你确认后它才执行。
