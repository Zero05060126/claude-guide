# 🧘 学习专注 · Study Focus

一个帮你保持学习专注的工具。检测到你打开抖音、B站等娱乐网站时，**自动拦截并转移到专注提醒页面**。

## ✨ 功能

- 🛡️ **自动拦截** — 浏览器扩展实时检测，在娱乐网站加载前就拦截
- ⏱️ **番茄钟** — 内置 25+5 番茄工作法计时器，带进度环
- 📊 **数据统计** — 记录每日拦截次数、专注时长、连续打卡天数
- 💬 **名言警句** — 内置 12 条中英文励志语录，随机轮换
- 🎨 **暗色主题** — 深色护眼设计，减少视觉干扰
- 📱 **响应式** — 手机、平板、电脑均完美显示
- 🔧 **可定制** — 自由添加/移除要拦截的网站

## 🚀 部署公开网页

### 方式一：GitHub Pages（推荐 · 免费）

1. 在 GitHub 新建仓库（如 `study-focus`）
2. 上传 `index.html` 到仓库根目录
3. 进入仓库 `Settings` → `Pages` → Source 选 `main` → Save
4. 等待几秒，页面 URL 类似 `https://你的用户名.github.io/study-focus/`
5. 在扩展弹窗的「重定向地址」中填入这个 URL

### 方式二：Netlify / Vercel

1. 注册帐号后，拖拽 `index.html` 到网页即可部署
2. 会得到一个 `xxx.netlify.app` 或 `xxx.vercel.app` 域名

### 方式三：Cloudflare Pages

1. 在 Cloudflare 控制台选择 Pages → 上传 `index.html`
2. 几秒内获得 `xxx.pages.dev` 域名

## 🧩 安装浏览器扩展

### Chrome / Edge / 任何 Chromium 浏览器

1. 打开浏览器，地址栏输入 `chrome://extensions/`
2. 打开右上角「**开发者模式**」开关
3. 点击「**加载已解压的扩展**」
4. 选择 `extension/` 文件夹
5. ✅ 扩展安装完成！点击工具栏图标可以配置

### 扩展配置说明

| 设置项 | 说明 |
|--------|------|
| **拦截开关** | 一键开启/关闭拦截功能 |
| **拦截列表** | 管理要拦截的网站域名（默认含 B站/抖音/YouTube/微博/知乎等） |
| **重定向地址** | 填入你部署的公开网页 URL（留空则使用扩展内置页面） |

## 🔒 隐私说明

- 所有数据存储在**浏览器本地**（localStorage + chrome.storage）
- **不**上传任何数据到服务器
- **不**收集任何个人信息
- 开源透明，代码可审查
